# แผนโครงสร้างเว็บและ SEO ท้องถิ่น — โลตัส สุขา 3 (TH/EN)

สถานะ: **แผน (draft)** ตรวจจากโค้ดจริงวันที่ 2026-11-17 · ยังไม่มีข้อมูล Search Console/ปริมาณค้นหา จึง **ไม่ประมาณอันดับหรือ traffic** · ข้อมูลสาขาจำนวนมากยังเป็น placeholder

## 1. โครงสร้างที่มีอยู่จริง (ข้อเท็จจริงจากโค้ด)

| URL | ภาษา | บทบาท | index? |
|---|---|---|---|
| `/` | th | หน้าเดียวครบ: Hero → โปรโมชัน → บริการ → เดินทาง → เวลา/ติดต่อ → สั่งออนไลน์ → ท้ายเว็บ | ใช่ (canonical ตัวเอง) |
| `/en/` | en | เนื้อหาเทียบเท่า | ใช่ |
| `/privacy.html`, `/en/privacy.html` | th/en | นโยบายความเป็นส่วนตัว | ใช่ (ค่าต่ำ) |
| `/404.html` | th+en | ไม่พบหน้า | noindex |

- **hreflang**: th / en / x-default ครบทุกหน้า ชี้กลับกันถูกต้อง (ตรวจแล้ว) และ `<html lang>` ตรงภาษา
- **canonical**: ตั้งเองทุกหน้า · **sitemap.xml**: 4 URL พร้อม xhtml:link alternate · **robots.txt**: Allow ทั้งหมด + ลิงก์ sitemap
- **Title/description**: หน้าหลัก title 50/52 ตัวอักษร, description 105/116 (อยู่ในเกณฑ์ ≤60/≤155)
- **OG/Twitter**: ครบ (รูป 1200×630) · **หัวข้อ**: h1 หนึ่งตัว, h2 ห้าตัวต่อหน้า
- **Schema**: `GroceryStore` ปัจจุบันมีแค่ name, url, image, inLanguage (ที่อยู่/พิกัด/โทร/เวลา/sameAs ยังไม่ใส่ เพราะเป็น placeholder → ถูกต้องตามหลักไม่เดา)
- **การวัดผล**: GoatCounter (ไม่ใช้คุกกี้) + event การกดปุ่ม · รอ Search Console

## 2. ช่องว่างที่พบ (เรียงตามผล/ความเร่งด่วน)

**P0 — ต้องแก้ก่อนเปิดจริง**
1. ข้อมูล NAP จริง (ชื่อ ที่อยู่ เบอร์ พิกัด เวลา) ยังเป็น placeholder → schema ยังบางและ local SEO ยังไม่ทำงาน
2. ยังไม่ได้ push / เปิด Pages → ไม่มี URL จริงให้ตรวจ
3. `description` ของหน้า privacy ยาว 242/270 ตัวอักษร (เกิน 155) → ควรทำ description สั้นเฉพาะหน้า
4. Search Console ยังไม่ยืนยัน → ยังไม่รู้สถานะดัชนีและคำค้นจริง

**P1 — ผลต่อการเข้าใจเนื้อหา**
5. เนื้อหาหลัก (เวลา โปรโมชัน บริการ ที่อยู่) **สร้างด้วย JavaScript** → Google รันได้ แต่ crawler/ตัวแสดงตัวอย่างบางตัวไม่รัน ควร pre-render อย่างน้อยเวลาเปิด-ปิดและที่อยู่ลง HTML ตอน build
6. `openingHoursSpecification` ถูกซ่อนจนกว่า `is_sample=false` (ถูกต้อง) แต่ต้องไม่ลืมเปลี่ยน
7. ไม่มี `Organization`/`WebSite` และ `BreadcrumbList` (หน้าเดียวจึงไม่จำเป็น) — ไม่ใช่ปัญหาตอนนี้
8. ไม่มีรูปจริงของสาขา → รูปสำคัญต่อ local pack และ OG; alt สองภาษารองรับแล้วในโค้ด

**P2 — เมื่อเนื้อหาโตขึ้น**
9. หน้าเดียวต่อภาษา เหมาะกับ POC แต่ถ้ามีเนื้อหาเฉพาะ (โปรโมชันย้อนหลัง ร้านค้าในศูนย์ ที่จอดรถ) ค่อยแยกหน้า (ดูข้อ 4)

## 3. การถือครองคำค้น (keyword ownership) — ต้องพิสูจน์ด้วยข้อมูลจริง

ยังไม่มีข้อมูลปริมาณค้นหา จึงเป็นสมมติฐานที่ต้องยืนยันด้วย Search Console หลังเปิด 2–4 สัปดาห์

| กลุ่มคำค้น | หน้าเจ้าของ | แหล่งที่แข่งด้วย | หมายเหตุ |
|---|---|---|---|
| โลตัส สุขา 3 / Lotus Suka 3 (ชื่อสาขา) | `/` และ `/en/` | Google Maps/GBP, เว็บทางการ | เป้าหลักของเว็บ แต่ GBP มักนำในผลท้องถิ่น |
| …เวลาเปิด-ปิด, …เบอร์โทร, …แผนที่, …โปรโมชัน | `/` (ส่วนที่ตรงกัน) | GBP, เว็บทางการ | long-tail ตามสาขา ตรงที่สุดกับเว็บนี้ |
| opening hours / phone / map + ชื่อสาขา (EN) | `/en/` | GBP | ต้องสะกดเหมือน Google Maps |
| คำกว้างระดับแบรนด์/หมวด (เช่น "โลตัส", "ซูเปอร์มาร์เก็ต") | **ไม่ใช่เป้าของเว็บสาขา** | เว็บทางการ (lotuss.com) | ระบุตรง ๆ ว่าไม่แข่ง เพื่อไม่ทำซ้ำเว็บแม่ ตามบรีฟ |

หมายเหตุสำคัญ: เว็บนี้ไม่ใช่เว็บทางการ จึงไม่ควรคาดหวังชนะคำระดับแบรนด์ ผลที่ควรวัดคือ **ชื่อสาขา + เวลา/เบอร์/แผนที่/โปรโมชัน** และการกดปุ่มโทร/นำทาง

## 4. โครงสร้างเป้าหมาย (ขยายเมื่อมีข้อมูลจริง)

- **ตอนนี้ (POC):** `/` + `/en/` หน้าเดียว ลำดับตามบรีฟ
- **เฟส 2 (ถ้ามีเนื้อหาจริงพอ):** แยกหน้าเฉพาะ เช่น `/promotions/`, `/stores/` (ร้านค้าในศูนย์), `/visit/` พร้อม `/en/…` ที่เทียบเท่า — ต้องมี hreflang คู่ canonical เองและลิงก์ภายในจากหน้าแรก แยกเฉพาะเมื่อแต่ละหน้ามีเนื้อหาไม่บางและไม่ซ้ำกับหน้าแรก
- **ห้ามทำ:** หน้าเมืองหรือหน้าคีย์เวิร์ดซ้ำเนื้อหา (doorway), รีวิว/ดาวปลอม, เนื้อหาคัดลอกจากเว็บแม่

## 5. SEO ท้องถิ่น (นอกเว็บ)

1. **NAP ตรงกันทุกตัวอักษร** ระหว่าง `config.json`, Google Business Profile, Facebook, Bing Places
2. GBP: ใส่ลิงก์เว็บนี้ (พร้อม `?utm_source=gbp&utm_medium=profile` เพื่อแยกใน GoatCounter) หมวดหมู่ เวลา รูป
3. Bing Places (ใช้บัญชี Microsoft/Outlook ได้) นำเข้าจาก GBP ได้
4. ลิงก์ขอรีวิวจริงใน `maps.review_link` และ QR ในสาขา (UTM `qr`) — ห้ามเขียนหรือซื้อรีวิว
5. เมื่อมีโดเมนของตัวเอง เปลี่ยน `site_url` + เพิ่ม `CNAME` + ทำ 301 และย้ายทรัพย์สิน Search Console

## 7. วัดผลอย่างไร (แยกชุดตัวเลข ไม่รวมเป็นคะแนนเดียว)
- **Search Console:** impressions/clicks/ตำแหน่งเฉลี่ยของกลุ่มคำชื่อสาขา, สถานะดัชนี th/en
- **GoatCounter:** ผู้เข้าชมตามแหล่ง (qr/facebook/line/gbp), event `call` / `navigate` / `line` / `order-web`
- **GBP Insights (ของเจ้าของ):** การโทร การขอเส้นทาง
- การเปลี่ยนแปลงหลังแก้เว็บเป็นข้อมูลเชิงสังเกต **ไม่ใช่การพิสูจน์เหตุและผล**

## 8. สิ่งที่ไม่ทำ / ไม่รับประกัน
- ไม่รับประกันอันดับ การเข้าชม หรือการถูกอ้างอิงโดย AI
- ไม่ทำ Markdown mirror ของทุกหน้า / `llms.txt` ตอนนี้ (เว็บมี 4 หน้าสาธารณะ เนื้อหาจริงยังไม่ครบ; ทำได้ภายหลังถ้าเจ้าของต้องการ ถือเป็นทางเลือก ไม่ใช่ตัวแปรอันดับ)
- ไม่ใส่ schema รีวิว/คะแนนดาว ถ้าไม่มีข้อมูลจริงที่แสดงบนหน้า

## 9. ความเสี่ยงและข้อสังเกตด้านความปลอดภัย
- ไม่มีหน้า admin บนเว็บ: ดูสถิติที่ GoatCounter (`lotus-suka3.goatcounter.com`) และ Search Console ซึ่งต้องล็อกอินด้วยบัญชีเจ้าของ
- ทุกอย่างใน repo เป็นสาธารณะ ห้ามใส่ token/รหัสผ่าน
